# v0.7.9 — 文档重构：三层文档、安装与排障手册、内部材料下线

## 这一版解决什么

v0.7.8 之前，用户说明和开发过程混在一起：新用户找不到安装入口，公开仓库里还带着维护者的
规划、审计与跨插件调研。这一版把文档按读者分成三层，重写全部对外文档，并把内部过程材料
移出仓库。**插件行为与 v0.7.8 完全相同，只想用插件的用户不需要升级。**

1. **用户文档**：README 重写为入口；新增 INSTALL（安装 / 升级 / 卸载 / 回滚）、五分钟快速开始、
   配置参考（28 个键的完整默认样例）、命令、卡片能力与限制、8 类症状的故障排查。
2. **开发文档**：CONTRIBUTING、架构、测试与门禁、发布流程、SECURITY 与行为准则。
3. **内部材料下线**：规划、审计、跨插件调研、交接与验证日志只保留在维护者本机，已加入
   `.gitignore`；门禁需要的冻结契约移到 `tests/fixtures/` 随仓库发布。公开 clone 里依赖
   本地归档的检查会明确打印跳过并计数，不会静默当通过。
4. **文档守卫**：`tests/check_docs.py` 检查版本三处一致、相对链接可达、对外文档不引用内部
   归档、README 行数上限；已并入 `run_fast.py` 第 1 步，`--full` 现在是 9 步。
5. **仓库更名**：GitHub 地址变为 `zayn-0101/LarkDeck`；插件 id、配置路径
   `plugins.entries.larkdeck.settings.*` 与 `/larkdeck` 命令保持不变，升级不用改配置。
6. **隐私清理**：对外文件里的维护者本机绝对路径与真实飞书消息 ID 已移除。

## 行为细节

- 无运行时变更：`core/` 代码只更新了注释里的文档路径。
- 配置键、默认值与命令与 v0.7.8 一致。

## 兼容与回退

- `plugin.yaml` 版本升到 0.7.9，homepage 指向新仓库名；其余字段未变。
- 回退：`git checkout v0.7.8` 后重启 gateway。

## 门禁

- `run_fast.py --full` 9 步全 `[OK]`；`test_units.py` 343/343；文档守卫 `DOCS OK`。

## 安装 / 升级

- 已安装用户不需要升级；要拿新文档执行 `git pull`（软链安装），或按
  [INSTALL.md](../../INSTALL.md) 的 `--copy` 升级步骤操作，然后 `hermes gateway restart`。
