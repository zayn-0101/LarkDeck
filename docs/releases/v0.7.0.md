# v0.7.0 — 正文来源切换为插件累积

## 这一版解决什么

1. 以前正文依赖 Hermes 的流式帧并事后剥离工具进度，仍可能混入进度行；现在正文只认模型文本增量，工具进度从结构上不再进入正文。
2. 会话归属不确定时，流式中间帧不再把内容串到其他会话。

## 行为细节

- 新增 `body_source`，默认 `own`；需要旧路径可显式设 `body_source: legacy`。
- 收尾时 Hermes 文本与插件累积按前缀或后缀关系取用，不再按分隔线切分，避免答案被截断或重复。
- 会话归属缺失、过期或漂移时，流式中间帧只显示空或占位；收尾使用 Hermes 的最终文本。
- `/stop` 按卡片实际显示过的正文重绘；执行失败的帧不会被写进答案正文。
- 面板标题不再包含模型名；页脚顺序为 状态 → 耗时 → 模型 → 上下文 → 卡短码。

## 兼容与回退

- `body_source` 为新增键，默认 `own`；`legacy` 作为过渡回退保留。
- 回退：先设 `body_source: legacy`；或 `git checkout v0.6.4` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [安装指南](../guide/installation.md)。
- 发布验证：门禁与真机验收通过。
