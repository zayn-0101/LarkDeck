# v0.7.1 — 卡片视觉层切换为结构化元素树

## 这一版解决什么

1. 卡片由文本拼装改为 CardKit 结构化元素树，新增顶部状态条、单行面板摘要、统一工具行、推理折叠块与 Working 心跳。
2. 状态条区分处理中（蓝）、已完成（绿）、已停止（黄）与执行出错（红）；面板摘要为 `💭 思考 Xs · 🛠️ 工具执行 · N 步`。
3. 失败回合显示红头红边；正文或页脚遇到卡片级错误时同卡降级，不直接掉成纯文本。

## 行为细节

- `visual_engine` 默认 `structured`；`legacy` 配置路径已退役，显式设置只产生一条 WARNING，行为仍是 structured。
- `card_status_header` 默认 `true`；设为 `false` 可隐藏顶部状态条。
- `show_reasoning` 默认 `false`；开启后推理正文以折叠面板展示，关闭时只保留「💭 思考 Xs」摘要行。
- 结构化样式覆盖流式卡、收尾整卡、`/stop` 重绘，以及非流式的发送与编辑回退路径。
- 页脚顺序：状态 → 耗时 → 模型 → 上下文 → 卡短码。

## 兼容与回退

- 三个键均为新增项，没有配置键改名。
- `legacy` 配置不再切换引擎；真正回退视觉层：`git checkout v0.7.0` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
