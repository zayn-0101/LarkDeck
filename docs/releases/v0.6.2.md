# v0.6.2 — 多行工具进度不再进入正文，默认启用彩色标签与紧凑字号

## 这一版解决什么

1. 模型连续调用多个工具、迟迟不写正文时，Hermes 会把「搜索行 + 读取行 + terminal 代码块」整段当作正文；旧规则只看第一行，多行块会落进答案区。
2. 面板默认观感偏灰、字号偏大：状态颜色与 12px 记法字号改为默认开启。

## 行为细节

- 模型尚未写正文时逐行检查整段内容：只有每一行都能判断为工具进度、且没有分隔符时才剥离；任何一行无法确认就保持原样。
- 代码块只有在确认对应运行中的 terminal 工具时才剥离，避免误删模型答案里的第一段代码。
- `panel_color_tags` 默认由 `false` 改为 `true`：成功绿色、运行中青绿色、失败 / 阻塞 / 超时红色、中止 / 跳过灰色，工具细节行灰色。
- `text_profile` 默认由 `off` 改为 `compact`：面板与页脚 12px，正文 14px。
- 收尾帧永不剥离；Hermes 后续新增的进度类型无法识别时保持原样，不会吞正文。

## 兼容与回退

- 两个默认值都可用配置恢复：`panel_color_tags: false`、`text_profile: off`。
- 回退：`git checkout v0.6.1` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [安装指南](../guide/installation.md)。
- 发布验证：门禁通过；彩色标签与字号视觉效果待真机确认。
