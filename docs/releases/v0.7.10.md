# v0.7.10 — 澄清确认更干净，状态卡改版

## 这一版解决什么

1. **澄清卡确认后不再出现内部 ID**：以前点击者显示名取不到时，会把 `open_id`（`ou_...`）
   直接拼在答案后面；用户看到的是一串无意义字符。现在只有拿到显示名才署名，否则只显示所选答案。
2. **`/larkdeck status` 改为分节卡片**：原来的状态卡是一长串纯文本行。现在分为
   「能力与链路」「能力探测」「记录」三段，配加粗标题、引用块、无序列表、两列记录表格、
   异常标红与分隔线，扫读成本明显降低。

## 行为细节

- 澄清卡（1.0 / 2.0 两种形态都改）：答案行规则为「有显示名 → `✅ 选项　—　名字`；
  拿不到 → `✅ 选项`」。点击、提交、回退逻辑均未改动。
- 状态卡展示层重写，**事实文本一个字节不改**：六条记录仍按原文拆成「项目 / 值」两列表格，
  没记录就写「无记录」，不写「正常」；`⚠️` 仍只由明确异常触发。
- 配置键、命令、卡片结构（面板 / 澄清 / 页脚）与 v0.7.9 完全一致。

## 兼容与回退

- 无新增 / 删除配置键，无默认值变化。
- 回退：`git checkout v0.7.9` 后重启 gateway。
