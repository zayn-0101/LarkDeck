# v0.7.6 — 兼容 Hermes 0.21.4 延迟平台加载

## 这一版解决什么

1. Hermes 0.21.4 改为延迟加载内置平台插件；旧写法在插件加载线程里读取内置平台时会与主线程互等，最终触发加载超时，LarkDeck 被丢弃、飞书退回纯文本。现在平台注册不再经过这把锁。
2. 升级后无需再全局关闭 `plugins.load_timeout_seconds`，超时保护恢复默认。

## 行为细节

- 老版 Hermes（没有延迟加载快照）继续走注册表查找，行为与 v0.7.5 以前一致。
- 0.21.4+ 已解析的内置平台直接复用；仍处于延迟状态时，直接导入内置模块并捕获完整的注册参数。
- 捕获失败时插件快速失败并写出明确错误，不会拖满加载超时，也不会静默丢失平台。

## 兼容与回退

- 建议删除为绕过此问题临时设置的 `plugins.load_timeout_seconds: 0` 等配置。
- 回退：`git checkout v0.7.5` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [安装指南](../guide/installation.md)。
- 发布验证：门禁与真机验收通过。
