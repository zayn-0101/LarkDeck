# v0.7.7 — 澄清选择后主卡即时更新

## 这一版解决什么

1. 点选澄清卡后，澄清卡本身会变为已确认，但主卡在阻塞工具返回前仍显示「等待你的选择…」与 `clarify · Running`，看起来像点击无效；现在主卡在点击后立即更新。
2. 多选澄清卡不会自动提交；现在提供「提交」按钮，勾选后可直接提交。

## 行为细节

- 收尾帧里 `clarify` 仍在运行、或正文仍是核心写入的等待占位时，不关闭主卡流；占位文案改写为 `⏳ 等待你的选择…`，已有正文保留。
- 点击成功后立即把 `clarify` 步骤标为完成，正文写回「✅ 已收到你的选择，正在继续…」；点「其他（我直接输入）」时保持等待输入，不假装完成。
- 真实工具结果到达后按工具调用 ID 覆盖即时状态，不产生重复步骤；迟到或重复点击只回提示，不会把已确认的卡退回待答。
- 多选卡放入官方 `form` 容器，提交按钮从表单提交结果中读取选中值并转成网关要求的数组。
- 只影响结构化 CardKit 与 2.0 澄清卡；`patch` 车道、降级车道与 1.0 澄清卡行为不变。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.7.6` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
