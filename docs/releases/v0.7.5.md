# v0.7.5 — 长任务心跳并入主卡，追问不再闪旧步骤

## 这一版解决什么

1. 长任务每 180 秒的 `⏳ Working — N min — …` 会新建一张中间卡；现在心跳合入当前结构化主卡的折叠面板标题，最终答案仍写同一张卡，心跳不碰正文。
2. 新回合开始时卡片会先闪出上一回合的工具步骤；现在新回合第一帧不再读取上一回合快照，从空面板开始。
3. 没有活跃主卡时只建一张专用静默卡并复用；多条活跃会话、降级中、面板关闭或刚收尾的安静窗口内一律抑制。
4. 明确不做跨回合合并：后台任务完成通知会开启独立新回合，不能把它误当成同轮重复收尾而吞掉。

## 行为细节

- 心跳只改面板标题，不写正文。
- `long_running_notifications: generic` 的任意心跳文案仍走 v0.7.4 静默卡，暂不并入面板。
- 无活跃主卡时创建的专用 Working 卡在真实终稿后仍留在时间线，不删除、不合并。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.7.4` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
