# v0.6.4 — 带前导分隔符的进度帧不再漏进正文

## 这一版解决什么

1. Hermes 侧正文仍为空（只含空白）时，工具进度会以「空行 + `---` 分隔符」开头；旧规则看到分隔符就保持原样，答案区出现分隔线、搜索行与 terminal 代码块。
2. 现在会先忽略开头的空白与分隔符，再判断整段内容是否都是工具进度；确认是进度就改为显示等待占位。

## 行为细节

- 只处理正文尚未开始、且开头只有空白与分隔符的帧；分隔符前有任何真实正文都保持原样，一个字不动。
- 保留 `⏳ 正在生成…` 占位，工具执行期间正文区不显示空白或进度。
- 收尾帧与 Hermes 新增进度类型等边界同 v0.6.2，无法确认时保持原样，不会吞正文。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.6.3` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁通过；彩色标签与字号视觉效果待真机确认。
