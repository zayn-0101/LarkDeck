# v0.7.2 — 面板交互定版与真机反馈收敛

## 这一版解决什么

1. 页脚信息过杂：去掉卡短码与段前缀 emoji，改为 状态 · 耗时 · 模型名 · 上下文用量；模型显示可读名称，不再显示原始 ID。
2. 加载时的「正在加载上下文…」文字观感差：改为会动、无文字的状态指示，首个正文 token 到达即移除。
3. 工具行图标风格不统一：改用飞书官方线性图标做文本前缀，运行中蓝色、成功绿色 `✓`，失败 / 超时 / 中止 / 跳过保留语义色。
4. 长回合可能因面板元素字段不合法导致整卡被拒，从而出现卡片与「⏳ Working — …」纯文本并存；本版修复字段并加校验。
5. 面板展开策略定版：运行中展开、收尾折叠，流式中间帧不再重写展开状态。

## 行为细节

- 新增 `streaming_panel_expanded`（默认 `true`）；`panel_expanded`（默认 `false`）只管收尾那一次。手动收起后，后续帧不会把面板顶开。
- `card_status_header` 默认改为 `false`；设为 `true` 可恢复顶部状态条。
- `tool_row_icon` 默认 `line`（官方线性图标），可设 `emoji` 回到 emoji 内联形态；运行中工具图标使用动态图。
- 澄清卡在表单容器中提交时，从表单提交结果中读取选项与输入值，不再被当成空提交；原有组件级回调路径不变。
- 修复 `panel_expanded: true` 在结构化卡片上被忽略，以及 `unified_panel: false` / `footer: false` 与「无过程数据不渲染空面板」在非流式回退路径上失效。
- `/stop` 重绘的结构化终态卡会正确关闭流式态。

## 兼容与回退

- `card_status_header` 默认值由 `true` 改为 `false`；其余为新增键，旧配置继续生效。
- 回退：`git checkout v0.7.1` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
