# v0.7.17 — 升级"装上了却没生效"：同名插件目录遮蔽

## 这一版解决什么

用户报的现象（2026-10-08，NAS）：**按文档升级到 v0.7.16，磁盘上文件确实换了、日志也打了自检通过，但新功能一个都没出现**。查下去发现磁盘上是 0.7.16、**实际加载的是 0.7.15**：`~/.hermes/plugins/` 里还留着按旧文档改名备份的 `larkdeck.bak-202610041311`。

机制（Hermes 侧）：它扫描 `$HERMES_HOME/plugins/*/` 的插件清单，注册表按清单里的 **`name`** 记账，**后扫到的同名顶层目录覆盖先扫到的**（`sorted(iterdir())` ⇒ 目录名字典序更大的赢）。于是：

- 旧版本改名留在 `plugins/` 里 ⇒ **新装的 `larkdeck` 永远不会被加载**；
- 而且**没有任何自动告警** —— `hermes plugins list` 会安静地显示生效的那个版本。

**根因在我们自己的文档**：升级/卸载/回滚三处都教用户把旧目录改名留在 `plugins/` 里（`mv … plugins/larkdeck.bak-$(date …)`）。本版把这条链子从文档、安装器、运行时三处一起修掉。

## 行为细节

- **`install.sh` 先检查同级同名目录**：会遮蔽本次安装的（目录名排序在 `larkdeck` 之后的，`larkdeck.bak-…` / `larkdeck-old` 都是）**直接拒绝安装**（退出码 3），并给出两条出路 ——
  - `./install.sh --copy --fix-shadow`：把它们搬到 `$HERMES_HOME/plugin-backups/`（**只 `mv`、不删除**）；
  - 或自己 `mv` 到 `plugins/` 之外。
  排序在前的同名目录只提示、不拒绝（它不会遮蔽本次安装）。读不到清单的目录算**无法判定**，同样拒绝、且**不会被搬动**。
- **启动自检行行末新增自证段**：`… · 插件 v0.7.17 @ /path/to/plugins/larkdeck` —— 回答"**现在跑的到底是哪一份代码**"。
- **存在会遮蔽本插件的同名目录时**：启动日志打 `WARNING`，`/larkdeck status` 在卡片**顶部**置顶一行 ⚠️（默认视图只给结论与出路，机制句在 `--detail`）。干净环境**一行都不多**。
- **文档**：升级/卸载/回滚的示例命令一律把备份放到 `plugins/` 之外（容器 / NAS 用 `${HERMES_HOME:-$HOME/.hermes}`），并补了"升级后 30 秒自查"；新增故障排查条目"升级没生效"。
- **发布工具**：`tools/setup_deploy_worktree.sh` 的软链备份也改到 `plugins/` 之外（它以前正是遮蔽源之一），`--apply` 会警告 `plugins/` 里残留的旧备份。

## 升级后 30 秒自查（**已经踩过坑的请先做这个**）

```bash
# ① 实际加载的是哪一份（版本必须是刚装的那版）
hermes plugins list | grep larkdeck
# ② 插件自己的自检行（行末带版本与目录）
grep '\[larkdeck\] 启动自检' "${HERMES_HOME:-$HOME/.hermes}/logs/agent.log" | tail -1
# ③ 在飞书里发 /larkdeck status：卡片首行的版本必须一致
```

- ② 行末**没有** `插件 v… @ …` 这一段 ⇒ 你跑的仍是 **0.7.16 或更早**（旧版不会打这一段）。
- 三条命令要在**网关同一环境、同一用户、同一 `HERMES_HOME`** 下执行（装在容器里就在容器内跑）。
- 发现 `plugins/` 里还有同名旧目录 ⇒ `./install.sh --copy --fix-shadow`（只搬不删），然后 `hermes gateway restart`。

## 诚实的边界

- **已经被遮蔽的进程不会自己报警**：旧 `larkdeck.bak-…` 排在后面时，Hermes 只 import 它 —— 本版新增的启动扫描与卡片提示**在它里面根本不存在**。所以对**已经处于遮蔽态**的用户，唯一主动渠道就是本说明 + 上面那 30 秒自查。
- 同理，**不跑 `install.sh` 的安装方式**（手工复制、脚本绕过）不会被安装器拦住；运行时告警也只在"启动后目录才发生变化"这类场景可达。
- 读不到清单的目录（权限 / 属主不同）无法判定会不会遮蔽，本版**如实说"无法判定"**并拒绝安装，而不是猜。
- 本版不新增/删除卡片元素；标题栏状态条仍默认关闭。
