# v0.7.3 — 面板细节字号与系统提示口径

## 变更（用户可见）

- **工具细节行**（`markdown` / `plain_text` 两宿主）与 **Error/Result 块**使用字面量
  `text_size: "x-small"`。细节行真机确认更小；Error 块因飞书 **fenced 代码块字号固定**、
  旧 `div.text=lark_md` 客户端忽略 `text_size`，最终改为 **`markdown` + 逐行 inline code +
  `x-small`**（用户选定形态③）：`**Error**` 标签与每一行代码一起变小，长行可折行；不拆元素。
  字面量，不随 `text_profile` 放大，无运行时自动回退。
- **已知系统提示去状态词**：Gateway online/restarting、Session database、Hermes update、
  cron/后台完成等已知系统提示整卡不渲染面板/状态头/页脚，不再出现 `✅ 已完成`；
  **真实回合卡一个字不动**。
- 顺手修正历史口径注释（context/i18n/adapter/cards/mutate_check）。

## 升级

- Mac 软链安装：`git -C <仓库> pull` → `hermes gateway restart`（网关进程不热重载模块）。
- NAS `--copy` 安装：拉取后重跑 `install.sh --copy`，再 `hermes gateway restart`。
- 回退：`git checkout v0.7.2` → 重启。
- 无配置键改名、无默认值翻转。

## 已知限制

- 系统提示识别是「默认回合 + 已知前缀负清单」；**未登记的新系统提示仍会按回合卡显示
  `✅ 已完成`**。发布前用 `send 判定 turn=` 日志复核**非原生/通知/命令车道**（真实回合走原生
  CardKit streaming、不经过 `adapter.send()`，不会产生该日志）；漏网先登记前缀再重跑全量变异。
- 长任务/多卡时中间卡的执行详情面板可能空白（原生流回退/多回合交错；已登记 v0.7.4，本批不修）。
- 飞书服务端限制：`text_weight` 字段不可用（`200621` 整卡被拒）；hex 颜色客户端忽略；
  fenced 代码块与 `div.text=lark_md` 的字号固定、`text_size` 无效。
