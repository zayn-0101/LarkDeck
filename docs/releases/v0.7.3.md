# v0.7.3 — 细节字号收敛与系统提示静默

## 这一版解决什么

1. 工具详情行与 Error / Result 块字号偏大、长内容难读：改用 `x-small`；Error 块改为逐行 inline code，长行可折行。
2. 网关在线 / 重启、会话数据库、Hermes 升级、cron 与后台完成等已知系统提示会显示成普通回合卡，带 `✅ 已完成` 与空面板；现在整卡不渲染面板、状态头与页脚。
3. 真实回答回合不受影响，`✅ 已完成` 页脚保留。

## 行为细节

- 细节字号为字面量，不随 `text_profile` 放大，也没有运行时自动回退。
- Error / Result 块不再使用字号会被客户端忽略的代码块样式；标签与每行代码一起缩小。
- 系统提示识别基于「默认回合 + 已登记的命令与系统提示前缀」；未登记的新系统提示仍可能显示为带 `✅ 已完成` 的回合卡。
- 未登记的命令回执（如 `/reset`、`/new`）当时仍可能显示 `✅ 已完成`，已在下一版处理。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.7.2` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
