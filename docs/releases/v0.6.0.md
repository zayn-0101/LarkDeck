# LarkDeck v0.6.0

CLS 观感改造：面板摘要、工具行与页脚重做，模型名/回合耗时移入状态优先页脚，
markdown 的 i18n 边界写清，并为 `<font color>` 增加可回退开关。

## 概要

- 折叠面板摘要改为 `💭 思考 Xs · 🛠️ 工具执行 · N 步`；模型名与回合耗时不再出现在
  面板标题，改到页脚（状态 → 耗时 → 模型 → 上下文 → 卡短码）。
- 工具行重做：每个工具使用独立图标与加粗英文动作词，带耗时与状态词；命令或 skill
  名另起灰色小字。
- 状态词/灰色标题/灰色细节支持 `<font color>`，但 **v0.6.0 默认关闭**：真机三类消费者
  视觉尚未确认，默认走无色降级，避免客户端不认时把标签原样画给用户。
- plain_text/i18n 节点继续跟随客户端语言；markdown 里的动作词/状态词固定英文，分区小标题、
  footer 状态、等待期占位、轮标题、折叠/续卡提示固定中文默认 —— 这些 markdown 文本不承载
  `i18n_content`，不会随客户端语言切换。

## 用户可见变更

- 面板标题不再显示模型与回合耗时；页脚承担这些信息，且状态在最前。
- 工具行状态词固定英文（`Succeeded` / `Running` / `Failed` / `Blocked` / `Timed out` /
  `Cancelled` / `Skipped`），完整提示句仍走 i18n。
- 新增配置 `panel_color_tags`，默认 `false`；确认飞书客户端支持 `<font color>` 后可显式
  打开：
  ```yaml
  plugins:
    entries:
      larkdeck:
        settings:
          panel_color_tags: true
  ```
  无色路径保留状态词文字与面板边框色，不是功能缺失。
- D1 边界：默认 CardKit 流式折叠态只显示「执行详情」；生产不写 panel header 局部更新，
  收尾/降级/`/stop` 走整卡替换。
