# v0.6.0 — 面板、工具行与页脚重做

## 这一版解决什么

1. 折叠面板信息杂、没法快速扫读：摘要改为 `💭 思考 Xs · 🛠️ 工具执行 · N 步`，模型名与回合耗时移到页脚。
2. 工具行只有名字：每个工具改为独立图标 + 加粗英文动作词 + 耗时 + 状态词，命令或 skill 名另起灰色小字。
3. 页脚顺序固定为 状态 → 耗时 → 模型 → 上下文 → 卡短码，一眼能看到回合结果。

## 行为细节

- 展开面板新增「💭 思考」与「🛠️ 工具执行」两个分区小标题。
- 工具状态词固定英文：`Succeeded` / `Running` / `Failed` / `Blocked` / `Timed out` / `Cancelled` / `Skipped`，完整提示句仍随客户端语言。
- 新增配置 `panel_color_tags`，默认 `false`。确认客户端支持 `<font color>` 后可在 `plugins.entries.larkdeck.settings` 中设为 `true`；无色路径保留状态词文字与面板边框色，不是功能缺失。
- markdown 中的动作词与状态词固定英文；分区小标题、页脚状态与等待期占位固定中文默认。

## 兼容与回退

- 无配置键改名；新增键默认关闭，避免客户端不支持 `<font color>` 时把标签原样画出。
- 回退：`git checkout v0.5.0` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [安装指南](../guide/installation.md)。
- 发布验证：门禁通过；`<font color>` 视觉效果待真机确认。
