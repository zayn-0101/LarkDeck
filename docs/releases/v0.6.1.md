# LarkDeck v0.6.1

修复：工具调用不再以 `🖥 terminal` + 代码块的形式出现在答案正文里。

## 问题

模型还没输出任何正文就先调用工具时，Hermes 核心会把工具进度块作为**唯一正文帧**
发到流式卡（空累积时不带 `---` 分隔符）。v0.6.0 的正文净化判据要求“累积非空且是
帧前缀”，因此这一帧原样落进答案区，用户看到 terminal 代码块；工具详情应在折叠面板里。

## 修复

- `_strip_core_progress` 新增“空累积”分支：工具窗口打开、累积完整且帧形状明确指向
  运行中工具（`🖥 terminal`、裸代码围栏、`{emoji} {tool_name}: "…"`）时返回空，
  卡片层显示等待占位；工具详情仍只在折叠面板。
- 形状不明确、工具窗口没打开、累积被上限冻结、收尾帧：全部保持原样（fail-open），
  不会吞正文。
- 新增单测 + 变异 `CLS-34`，并把 R11-2/R11-4/R11-9 的锚点对齐新的判据顺序；
  `check_hooks.py` 的前提核对增加“空累积真实合成帧必须剥成空”。
