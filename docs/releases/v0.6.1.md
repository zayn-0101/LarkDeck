# v0.6.1 — 工具调用不再以 terminal 代码块出现在答案正文

## 这一版解决什么

1. 模型还没写正文就先调用工具时，Hermes 会把工具进度当作唯一正文发送，答案区于是出现 `🖥 terminal` + 代码块；工具详情应只留在折叠面板。
2. 现在模型尚未写正文、且内容能明确判断为运行中工具进度时，卡片改为显示等待占位，不再展示代码块。

## 行为细节

- 只处理能明确识别的单行工具进度；无法确认的内容、已有正文的帧和收尾帧都保持原样，不会吞正文。
- 工具详情仍然只出现在折叠面板里。

## 兼容与回退

- `panel_color_tags` 保持默认 `false`；无配置键改名、无默认值翻转。
- 回退：`git checkout v0.6.0` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁通过；`<font color>` 视觉效果待真机确认。
