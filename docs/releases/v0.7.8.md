# v0.7.8 — 思考面板：手动展开/收起 + 轮结束自动折叠 + show_reasoning auto

## 这一版解决什么

1. **思考展示不再需要 LarkDeck 自己配开关**：`show_reasoning` 默认改为 `auto`，跟随 Hermes
   的 `display.show_reasoning`（平台覆盖优先）。用户在飞书里 `/reasoning on|off`，或者在
   Hermes 配置里改 `display.show_reasoning`，下一次交互就跟着变；`on`/`off` 仍可显式覆盖。
   Hermes 没开 `plugins.stream_reasoning_deltas` 时插件收不到推理增量，此时 auto 按关闭
   处理，并在 `/larkdeck status` 里说明「Hermes 未发送 reasoning delta」。
2. **每轮思考都是可手动展开/收起的子面板**：标题统一为「第 N 轮思考 · X.Xs」。
   当前轮与已结束轮都由用户控制；已存在的子面板后续帧不再重放 `expanded`，所以手动状态
   不会被下一个 token 顶掉。
3. **一轮结束时立刻自动折叠**：子面板 element_id 从 `live` 换成 `folded`，并只带一次
   `expanded=false`。真机探针结论：同一个 element_id 上改 `expanded` 会被客户端的手动状态
   覆盖（顶不动）；换新 element_id 才会按 `false` 重建并折叠。
4. **折叠提示去掉前导省略号**：`…已折叠 N 条早期思考/工具记录` 改为 `已折叠 N 条…`，
   `…更早的 N 轮已折叠` 改为 `更早的 N 轮已折叠`。`…已省略 N 字符` 保留 `…`（那是被截断的
   尾巴，语义不同）。

## 行为细节

- 轮次定义：一段连续推理被正文或工具事件打断 = 一轮。当前轮在第一个出现帧带
  `expanded=true`，之后省略；轮结束时 `finalized=true`，换 id 并带一次 `expanded=false`。
- 手动收起当前轮、手动展开已结束轮都会保留，直到用户再次操作（后续内容帧不再重放展开态）。
- `show_reasoning=auto` 解析顺序与 Hermes 自己的 `resolve_display_setting` 一致：
  `display.platforms.feishu.show_reasoning` → `display.show_reasoning` → 平台档位默认值。
  读不到 Hermes 配置时 fail-closed（按关闭）。
- 会话列表/面板摘要行仍然保留：即使推理正文关闭，用户也能看到「思考 Ns」的耗时摘要。
