# v0.7.8 — 思考面板手动折叠与 show_reasoning 自动跟随

## 这一版解决什么

1. 思考内容原来需要单独配 LarkDeck 开关；现在 `show_reasoning` 默认 `auto`，跟随 Hermes 的 `display.show_reasoning`（平台覆盖优先），也可在飞书用 `/reasoning on|off` 覆盖。
2. 每轮思考改为独立子面板，标题为「第 N 轮思考 · X.Xs」，支持手动展开 / 收起，后续流式内容不会把状态顶回。
3. 一轮结束时子面板自动折叠。
4. 折叠提示去掉前导省略号：「已折叠 N 条…」与「更早的 N 轮已折叠」；表示截断的「…已省略 N 字符」保留省略号。
5. 收尾卡偶尔只剩空面板：现在每帧缓存本回合面板数据，终局遇到竞态也能恢复内容。

## 行为细节

- `show_reasoning=auto` 的解析顺序：`display.platforms.feishu.show_reasoning` → `display.show_reasoning` → 平台默认值；读不到配置时按关闭处理。
- Hermes 未开启推理增量时，`auto` 按关闭处理，并在 `/larkdeck status` 说明原因。
- 旧布尔 `show_reasoning: true` / `false` 继续有效，分别等价 `on` / `off`。
- 摘要行始终保留：即使推理正文关闭，也能看到「思考 Ns」耗时。

## 兼容与回退

- `plugin.yaml` 中 `show_reasoning` 类型由布尔改为字符串，默认 `auto`；旧配置升级后不会失效。
- 回退：`git checkout v0.7.7` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁与真机验收通过。
