# v0.7.11 — 状态卡文案与标记统一

## 这一版解决什么

`/larkdeck status` 的信息已经分区了，但文案还混着两套语法：「已接管 / 就绪 / 完整」和
「无记录（累计 0 次）」/「无记录」并存，口径说明也偏口语。这一版把**展示层**统一：

- **标记统一**：`✅` 有数据 / 零计数、`⚠️` 明确异常、`○` 没有数据、`🕒` 时长；每个分区共用同一套。
- **语法统一**：所有值都是「标记 + 标签：值」，例如「✅ 会话归属：就绪」「✅ 缺失接口：无」。
- **零与空分开**：零计数写「0 次」，没有数据显示「无记录」，不再互相混用。
- **口径正式化**：「统计口径：本卡数字为进程级累计，含本进程全部会话。」
- **去重**：能力/链路不再重复出现一次「能力探测」；写卡按帧计数的口径从表格单元格移到脚注。

## 行为细节

- 状态卡结构：加粗标题 → 口径引用块 → 「能力与链路」「能力探测」两个列表 → 「记录」表格 →
  帧数口径脚注 → 分隔线 + 命令提示。
- 事实与判定逻辑不变：没记录就写「无记录」、绝不写「正常/健康」；`⚠️` 只由明确异常触发
  （未接管 / 钩子不全 / 命令未注册 / 世代裂脑 / 失败计数）。
- 其它命令（`/larkdeck config`、`/larkdeck help`）、卡片、面板、配置键均无改动。
