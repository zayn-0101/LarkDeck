# v0.6.3 — 长工具回合恢复「正在生成」占位

## 这一版解决什么

1. v0.6.2 剥离空正文里的工具进度后，工具连续运行时卡片只剩折叠面板，正文区像卡住了；现在流式中间帧显示 `⏳ 正在生成…`。
2. 真正没有正文的回合不应永远停在等待文案：收尾帧不带占位。

## 行为细节

- CardKit 流式中间帧正文为空时保留 `⏳ 正在生成…`，首个正文 token 到达即替换。
- 收尾帧（非流式）不写占位。
- 面板、页脚、状态色与工具进度位置不变；工具进度仍只在折叠面板里。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.6.2` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [INSTALL.md](../../INSTALL.md)。
- 发布验证：门禁通过；彩色标签与字号视觉效果待真机确认。
