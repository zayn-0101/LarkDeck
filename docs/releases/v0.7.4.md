# v0.7.4 — 系统 / 命令回复静默与长任务面板修复

## 这一版解决什么

1. `/reset`、`/new`、`/reload-mcp`、`/reload-skills`、`/resume`、`/stop`、`/reasoning`、标题 / 页脚 / 模型与审批等命令回复会显示成普通回合卡，带 `✅ 已完成` 与空面板；现在命中已登记前缀后整卡不渲染面板、状态头与页脚。
2. `/larkdeck` 自诊卡同样静默；真实回答回合的 `✅ 已完成` 保持不变。
3. 长任务或多卡交错时，终局帧没有过程数据会渲染空白面板壳；现在不再渲染空面板，状态色由页脚承载。
4. 真机确认 `show_reasoning` 的嵌套面板可以展开；默认仍为关闭，渲染结构不变。

## 行为细节

- 静默基于已登记的命令与系统提示前缀；未登记的回执仍可能显示为普通回合卡，发现后登记前缀即可覆盖。
- 长任务面板修复只影响没有过程数据的终局帧，有内容的回合面板照常显示。

## 兼容与回退

- 无配置键改名、无默认值翻转。
- 回退：`git checkout v0.7.3` 后重启 gateway。

## 安装 / 升级

- 已安装用户：软链安装拉取后重启 gateway；`--copy` 安装拉取后重跑 `./install.sh --copy`，再重启；两种路径详见 [安装指南](../guide/installation.md)。
- 发布验证：门禁与真机验收通过。
