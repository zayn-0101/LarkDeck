# v0.7.4 — 系统/命令回复静默 + 长任务面板修复

- **Hermes 本地化系统/命令回复静默**：`/reset`、`/new`、`/reload-mcp`、`/reload-skills`、
  `/resume`、`/stop`、`/reasoning`、title/footer/model、approve/deny 等命令回复命中登记
  header 后整卡不渲染面板/状态头/页脚；`/larkdeck` 自诊卡同样静默。真实回合的
  `✅ 已完成` 一个字不动。
- **长任务/多卡中间卡面板空白**：终局帧快照无过程数据时不再渲染空 shell；状态色由页脚承载。
- **已知限制**：未登记的命令回执仍可能显示 `✅ 已完成`（内容负清单无法穷尽；上游
  `EphemeralReply`/slash 派发结构信号未进 metadata），发现后登记前缀并重跑全量。
- **show_reasoning 嵌套面板**：探针确认内层可展开；默认 `false` 维持，不改渲染结构。
- **升级**：`git pull` → `hermes gateway restart`；回退 `git checkout v0.7.3` → 重启。
- **门禁**：全量 6 分片数字待冻结提交跑完回填（未跑前不写）。
