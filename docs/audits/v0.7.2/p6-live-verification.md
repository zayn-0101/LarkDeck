## 追加决定（2026-09-22）：A1 展开时序**保持不变**

用户观察并提问：「现在是正文完整显示完，面板才收起来，对吧？是特意这么设计的吗」——并提议
「工具执行完就立刻收起、随后正文开始吐字」。讨论后**用户复确认维持现状**（原话：「这个场景我明白了，
这么看来还是目前这种逻辑比较合理，对吧」）。

理由（写下来免得下次又被当成缺陷重提）：

* 面板是**过程视图**，一个回合的过程只有到**回合结束**才算走完；「正文→工具→正文」的**交错回合**里，
  第一次出正文时工具往往还没跑完 ⇒ 那时收起会把后续过程藏起来（要手动展开才看得见）。
* 收尾折叠是**状态**（收尾整卡 patch 决定），不是手势：中间帧**刻意省略 `expanded`** ⇒ 永远不与
  用户的手动收起/展开冲突（2026-09-22 真机已验：「收着的」）。
* 已知代价：简单回合（工具跑完即写答案）里面板会一直开到正文吐完。**登记为可接受的取舍**；
  若日后日常使用中仍觉得别扭，v0.7.3 可再评估「出正文 + 最近数秒无新工具才收起」这类带防抖的规则
  （不是「第一次出正文就收」）。
