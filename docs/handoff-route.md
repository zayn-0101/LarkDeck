## 3. 已查证的事实（这一轮的产出，别再重查）

### 3.1 六家的升级代价必须分三类（**我第一版写错过一次，见 `6bd98dc`**）

| 类型 | 谁 | 升级后要做什么 | 坏的时候什么样 |
|---|---|---|---|
| **A. 安装期改磁盘源码** | HFC / CLS / FC | **每次升级都要重跑 install**（`hermes update` 覆盖被改过的文件） | 明确：`verify` 报 `Incompatible` 或钩子消失 |
| **B. 运行时 monkeypatch** | AP / ALS / HLS | **什么都不用做** | **静默失灵**：私有名改名 ⇒ 只打 WARNING ⇒ 卡片链路整条消失，等作者发新版 |
| **C. 官方插件契约** | **我们** | **什么都不用做** | **fail-open**：退回纯文本 + 留日志，消息永不丢 |

**凭据**：CLS/FC 的 `patcher.py` 把 `<HERMES_HOME>/hermes-agent/` 下的 `run.py` 备份成
`run.py.hermes_lark.bak` 后改写磁盘；HFC 用 `install/patcher.py` + manifest + recovery。
FC 的 INSTALL 原文：「`Hooks gone after Hermes update`｜Hermes update **overwrote patched files**｜
`Re-run verify + install`」；CLS 的 Update 段是 `uninstall`（remove old injection）→ `verify` → `install`。

> **结论口径（重要）**：**「不用重装」不是我们独有的优势** —— B 类同样满足用户的原始要求。
> **我们相对 B 类的优势只剩两条**：① 不依赖任何私有名 ⇒ 不会随上游内部重构**静默**失灵；
> ② 一旦不适配**必定退化成纯文本并留痕**，而不是无声消失。**别再把「不用重装」当主要卖点。**

* 本轮新增的两条自我教训（写给下一次）：
  1. **`repr`/三引号会把反斜杠折叠** —— 生成 patch 时 `\\` 会变成 `\`，于是断言实际在找一个
     反斜杠而不是两个（JSON 里会再转义一层）⇒ 白红一次。改断言看**元素内容**而不是 `json.dumps`。
  3. **门禁不稳会**反向**污染变异结论（2026-09-15 实测）**：`tests/test_units.py` 的
     `test_adapter_panel_wiring` 里 `assert "⏱ 12.3s" in header` 用的是
     `time.monotonic() - 12.3`，而**两次调用之间是真实间隔** —— 负载高时（同时跑变异验证器 +
     子代理）能超过 50ms ⇒ 四舍五入成 `12.4s` ⇒ **偶发假红**。危险的地方不在「红」本身：
     变异验证器把「红」当作**判别力证据** ⇒ 一条本来没牙的变异会被误判成「被抓住了」，
     **结论正好写反**。已改成 `re.search(r"⏱ 12\.[0-9]s", header)`（保留格式与量级）。
     ⚠️ **另有一条偶发未定名**：重负载下变异验证器的基线红过一次（`193/194`），
     此后连跑 **11 次全绿、未能复现** ⇒ 如实登记为「**观察到 1 次、未证实**」，不当结论。
     **操作纪律**：基线在负载下不绿时，**先怀疑环境再怀疑代码**，换安静时刻重跑再下判断。
  4. **审计的自制变异台挖出的是真缺陷，不是「断言没牙」**：它把 JSON 值类收紧后**全绿**，
     顺着查下去发现 —— 旧值类 `[^"]*` 在**转义引号**处**提前收尾**，于是只涂掉前半截、
     后半截照旧露在卡上（实测输出：`{"password": "***"jwt"}`）。**半截凭据同样是凭据**，
     而且它看起来像「已经处理过了」，比完全不脱敏更危险。修法：值类换成标准 JSON 字符串体
     `(?:[^"\\]|\\.)*`；守卫 `G1-11`/`G1-12`（两条都实测变红）。
     **教训：「改坏却全绿」常常不是断言写错了，而是那条断言没覆盖的形状本身就是个缺陷。**
  5. **金标快照的目录名必须叫 `larkdeck`**：我一度把它命名成 `good`，于是 `import larkdeck`
     解析到了**隔壁的活副本** —— 门禁自检当场拦下（「门禁测的不是这份代码」）。
     这是这类「二类假绿」在本项目的**第三次**出现，却是**第一次被自动拦住**
     （前两次都直接变成假绿）⇒ R11-B2 加的那道自检，价值在这里得到实证。

  2. **变异红 ≠ 用例不空**：`G1-4` 一开始全绿，因为断言只直接调 `redact_inline_secrets`、
     **没走 `_args_preview`**（验函数不验接线）；`G1-5` 的「不误伤」用例用了**数字**值而规则要求带引号
     ⇒ 用例本身恒真。两条都是靠「撤掉修复必须变红」这条纪律自己暴露的。
